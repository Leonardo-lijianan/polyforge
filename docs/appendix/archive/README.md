**为什么归档而非删除**：它们记录了设计决策的来龙去脉（为什么这么定、走过什么弯路），对理解工具有参考价值。

**为什么正文之外还需要它们**：正文是「结论」，归档是「过程」。读正文懂「是什么」，翻归档懂「为什么」。
